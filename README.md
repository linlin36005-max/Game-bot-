# Novel Game Bot

Virtual 2D/3D Telegram game bot using Coins/Points only. Coins have no cash value.

## Play
- /2d 57 100 or /play2d 57 100
- /3d 123 100 or /play3d 123 100

## Round time
Owner can add rounds with 12-hour time, at the hour or half-hour:
- /addtime 6 PM
- /addtime 6:30 PM

## Result
Owner enters the actual round number:
- /result 6:30 PM 57
The actual number is shown immediately in the current chat and appears in the Rounds view.
